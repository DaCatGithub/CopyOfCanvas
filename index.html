NHIỆM VỤ THỰC HÀNH

Chủ đề: THIẾT KẾ TRANG WEB "GÓC HỌC TẬP CỦA EM"

Em hãy thực hiện theo hướng dẫn bên dưới để tạo một trang web giới thiệu góc học tập cá nhân.

Bước 1. Tạo thư mục và file

  1. Mở Visual Studio Code.
  2. Tạo thư mục có tên OnTapHTML.
  3. Tạo hai file trong thư mục:
  1. index.html: Viết nội dung HTML.
  2. style.css: Viết mã CSS trang trí trang web.
Lưu ý: Hai file phải nằm trong cùng một thư mục để liên kết CSS hoạt động.

Bước 2. Viết mã HTML

Mở fileindex.html, nhập đoạn mã sau:
